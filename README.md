# UAC Healthcare Analytics Dashboard

## Overview
This project analyzes healthcare system capacity and operational load for the Unaccompanied Alien Children (UAC) Program.

## Features
- KPI Monitoring
- System Load Analytics
- Backlog Analysis
- Net Intake Trends
- Streamlit Dashboard

## Technologies Used
- Python
- Pandas
- Plotly
- Streamlit

## Run Project

```bash
python notebooks/clean_data.py
streamlit run app/app.py
